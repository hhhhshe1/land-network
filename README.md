# Land Network

واجهة أولية عربية/إنجليزية لموقع استضافة بوتات Discord.

## التشغيل محليًا
تحتاج إلى تثبيت Node.js على الكمبيوتر:
1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ `npm install`
4. نفّذ `npm run dev`
5. افتح الرابط المحلي الذي يظهر في الطرفية.

## النشر
يمكن نشر واجهة Vite الثابتة على Vercel أو Netlify:
- أمر البناء: `npm run build`
- مجلد الناتج: `dist`

## مهم
هذه نسخة واجهة أمامية فقط. تسجيل الحسابات، رفع الملفات الحقيقي، تشغيل/إيقاف البوتات، السجلات الحية، وإدارة الموارد غير مفعّلة. يلزم بناء Backend وخادم تشغيل مع عزل آمن للملفات والعمليات قبل استقبال ملفات المستخدمين.
